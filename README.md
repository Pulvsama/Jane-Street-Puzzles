Jane Street Puzzles

This repository contains my personal attempts at solving Jane Street puzzles.

The goal is not necessarily to provide the optimal solution, but to explore ideas that I find interesting and to document my own approach to each puzzle. Some solutions may be incomplete, inefficient, or simply different from the best-known approach.

Each puzzle has its own folder with the code, notes, and experiments related to that puzzle.
